HOW IT GROWS

毎日の会話が、そのまま養分になる

  1. 01

    話す

    Claude・GPT・Gemini。いつものAIで、いつもどおり仕事をする。

  2. 02

    読み取る

    会話の中から、NOBORU が下した判断と、その理由を読み取る。

  3. 03

    積み重なる

    判断の記録が RAG にたまり、NOBORU の考え方の地図が広がる。

  4. 04

    次の会話で生きる

    どのAIで話しても、積み重なった判断を踏まえて答える。

そして、また話す。
この輪が一周するたびに、クローンの精度が上がっていく。

ONE MEMORY

どのAIで話しても、同じ記憶につながる

使う画面は、Claude や ChatGPT のデスクトップアプリ。ブラウザから Claude・ChatGPT・Gemini を使うこともできます。基本は、安くて賢いクラウドのAIを、いつもどおり使うことです。

記憶とRAGは、各社のAIの中ではなく、AI NOBORu の側にあります。だから Claude で話しても、GPT で話しても、Gemini で話しても、同じ記憶と知識、そして同じクローンの判断を使えます。

44 LANES

話しかけるだけで、44本のレーンが動く

AI NOBORu は、Codex のレーンを14本、Claude Code のレーンを20本、Gemini のレーンを10本、合わせて44本持っています。レーンごとにAIのモデルを置き、並列に開発を進めます。

置けるモデルは、Claude の Fable・Opus・Sonnet 5.5、GPT-6 Astra・GPT-6 Luna、Gemini 3.8 Flash、手元で動く Qwen3.6:35B-A3B・Gemma4:12B・Gemma4:26B-A4B など。Codex や Claude Code のレーンに、Gemini や Qwen を置くこともできます。

NOBORU がするのは、Claude デスクトップのチャット欄で Opus に頼むことだけ。Opus が仕事を分けてレーンに渡し、進み具合と結果をチャット欄で報告します。

BLIND SPOTS

AIの盲点に、旗を立てる

ここでいう「AIの盲点」とは、NOBORU や AI NOBORu は知っているのに、世界の主要なAIがどれも知らないことです。

AI NOBORu は、作り手も国も違う8つのAIとつながっています。

  • Claudeアメリカ
  • GPTアメリカ
  • Geminiアメリカ
  • Grokアメリカ
  • DeepSeek中国
  • Qwen中国
  • Mistralフランス
  • PLaMo日本
  1. 01NOBORU が知っていることNOBORU や AI NOBORu が知っている事柄を取り上げる。
  2. 028つのAIに調べさせる同じ事柄を、8つのAIそれぞれに調べさせる。
  3. 038つとも知らなければ、旗を立てる「AIの盲点」として、AI NOBORu の中の盲点の倉庫に収める。

NOBORU や AI NOBORu の側が間違っていた時は、盲点として扱わず、集めません。8つのAIが調べた上で、本当に知らなかったと分かった事柄だけが、AIの盲点になります。

AIは新しい版が出るたびに賢くなり、昨日の盲点が、今日はもう盲点でなくなることもあります。そのため、集めた盲点は定期的に8つのAIで確かめ直し、盲点の倉庫を棚卸ししています。

PRIVATE RAG

クラウドAIの性能を使いながら、中身は外に出さないRAG

これまでのプライベートAIは、二つに分かれていました。

  • クラウド型：高性能なクラウドのAIを使う代わりに、情報が外に出ることを受け入れる。
  • 完全ローカル型：情報を守る代わりに、自分の機械で動くオープンモデルだけで我慢する。

賢さを取るか、秘密を取るか。どちらかを諦めるしかありませんでした。AI NOBORu は、その二択をやめました。

調査結果や論文の結果、成果物の一部、それらの要約といった RAG の部品は、Claude や GPT-6 Astra といった高性能なクラウドAIに作らせます。クラウドに渡すのは、見せてよい材料だけです。

スマートフォンづくりに似ています。基板、マイク、メモリー、CPU、ネジは、それぞれ専門の会社が作り、メーカーはそれを自社の工場で組み立てます。部品を作った会社が、組み立てた後の製品や、それを使う人のデータに触れることはありません。

できた部品は、プライベートRAGへ一方向にだけ運び込まれます。部品の組み立ても、毎日の実際の利用も、担うのは自分のパソコンや NAS で動くオープンモデル（Qwen や Gemma など）だけです。それも、クラウドのAIとは別の画面から使います。クラウドのAIには、プライベートRAGを読む経路そのものがありません。

プライベートRAGの護り方は、AIへの「お願いレベル、プロトコルレベル」ではありません。RAGデータの置き場と、通り道そのもので閉じています。
