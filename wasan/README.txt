WASAN — Japanese and English Mathematics Laboratory
AI NOBORU — https://www.aiofonesown.com/

This package contains the bilingual WASAN Mathematics Laboratory with 83 calculators and seven reading pages in each language.

Open:
- Japanese: index.html
- English: en/index.html
- JavaScript-free English calculator reference: en/calculators.html
- Downloads and attribution: downloads.html / en/downloads.html

The 83 calculators are arranged in six learning chapters. This is a learning order, not a claim about historical chronology or priority. Historical sources, later scholarship, and modern reconstructions are identified separately in the site.

Serve the files over HTTP or HTTPS and keep the directory structure intact. JavaScript module files (.mjs) must be served with a JavaScript MIME type. For local use, run a small local web server rather than double-clicking index.html.

The installation kit in downloads/AI-NOBORu-aiofonesown-kit.zip contains a wasan/ folder that can be placed below an existing website root without replacing the existing home page.
